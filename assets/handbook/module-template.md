## 当前行为与关键约束

按已分析入口解释条件、操作对象、数据变化、关键分支、实际执行顺序和结果。正常路径用正文或步骤表完整说明一次，资源表补充操作细节，不再复述同一过程。共用规则链接到权威段落，保留当前入口的适用条件和差异。

### 数据库、中间件与外部调用

为每个已分析入口列出直接、间接及异步分支涉及的实际表与资源，并对应业务步骤。共用清单标明各入口使用项；已确认不使用的类型在当前范围注明，未查清的依赖列为缺口。不能只罗列技术栈。

| 入口 / 步骤 / 条件 | 类型与实际资源 | 操作与业务用途 | 关键字段 / 关联标识 | 事务 / 异步 / 失败影响 | 实现、SQL或配置证据 |
|---|---|---|---|---|---|

填写各资源实际名称、操作、关联字段、配置来源和失败影响。共享配置定义链接 system，本页说明当前入口如何使用；不输出凭据。

### 事务、完成状态与失败处理

说明事务提交、事件/消息发出、异步完成和最终业务成功分别在哪一步；部分失败保留什么状态，如何判断完成或需要补偿。锁、状态过滤与副作用幂等分别说明，未核对重复执行条件时不宣称幂等。

关键结论建立 claim：行为关联实际实现，数据操作关联调用及 SQL / 实体映射，中间件关联使用方法与相关配置。缺少证据时标记 unknown / unverified；关键本地链路未查清时 coverage 使用 known-gap。
