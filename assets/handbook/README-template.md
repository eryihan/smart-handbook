检索词使用项目中的业务名称、问题症状、技术入口和业务编号，链接到对应模块、流程和代码。

## 模块与流程入口

从[模块地图](./map.md)定位 module / flow；全局概念和系统边界见[系统说明](./system.md)。

## 覆盖状态与缺口

从清单与 check 的派生结果汇总已发现、已验收、待分析、待复验和有缺口的入口；与各页面 coverage 核对。明确已分析范围、未检查目录和未归属入口，不能把建页或文件归属数量当作业务覆盖。详细业务边界以模块或流程页为准。

展示 full / navigation 模式、初始化进度和续跑位置，注明目标版本与实际记录时间。逐入口进度在 `.inventory.json`，实际场景及阅读结果在 `.reviews/`，来源指纹与运行验证在 `.state.json`；正文只汇总当前结果。全量完成需要所有纳入范围的入口与本地业务来源有有效验收证据；存在失败题、未分析入口或失效记录时保留未完成。清单缺失或损坏时注明初始化产物不完整。
