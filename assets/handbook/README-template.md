## 项目定位

填写系统职责、适用环境和所读取的目标代码版本。版本或环境未确认时标记 unknown。

## 常见任务导航

| 业务词 / 症状 / 技术入口 / 业务编号 | 模块或流程 | 源码入口 |
|---|---|---|

检索词使用项目中的业务名称、问题症状、技术入口和业务编号，链接到对应模块、流程和代码。

## 模块与流程入口

从[模块地图](./map.md)定位 module / flow；全局概念和系统边界见[系统说明](./system.md)。

## 覆盖状态与缺口

从各页面 metadata 核对并汇总 navigation-only / documented / known-gap，明确深入分析的入口或用例，不能把建页数量当作业务覆盖。已分析范围的详细边界以模块或流程页为准。注明未检查目录和未归属入口。

从 `.inventory.json` 展示 full / navigation 模式、初始化进度、未完成业务和续跑位置，注明目标版本与实际记录时间。来源和验证详情保留在 `.state.json`，历史记录不表示当前行为已重新确认。全量完成需要范围内业务的源码复核与独立阅读验收；清单缺失或损坏时注明初始化产物不完整。

## 使用方法

按[工作指南](./working-guide.md)确认目标版本，从页面引用读取相关代码。需要判断当前行为时核对实现和运行证据。
