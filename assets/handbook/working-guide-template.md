## 从业务找到页面

从 [README](./README.md) 的常见任务进入相应 module / flow；完整模块索引见 [map](./map.md)，术语含义见 [system](./system.md)。

补充本项目适用的检索词、业务编号和阅读顺序。单模块动作读模块页，跨模块和异步业务读流程页；不要在本页重写业务步骤、规则或状态表。

## 定位实现与适用版本

说明本项目路径、类型/方法名、SQL和配置的引用方式，以及从页面到实现的定位示例。仓库相对 path 从项目根目录解析，line 用于辅助跳转。

目标版本与整体覆盖见 README，各入口分析范围见所属业务页。部署版本未经确认时，手册的静态结论不能直接代表线上行为。

## 反馈手册问题

发现缺项或与代码不一致时，给出页面和段落、对应入口、目标代码版本、实现位置，以及无法从手册确认的问题。未读完的分支说明下一处证据，不自行补推。

本页说明如何阅读和反馈，不执行功能开发、应用排障或数据操作。手册更新与审计的命令用法通过已安装 Skill 的 `handbook help` 查看，当前进度仍以 README 和清单为准。
