# handbook audit

按任务范围重新检查 Handbook 的结构、来源、导航覆盖和关键内容。

## 检查与复核

从 Skill 安装目录运行脚本，`--root` 指向目标仓库：

```sh
python3 "<skill-directory>/scripts/handbook.py" check --root "<project-directory>" --format json
```

1. 确认目标版本和旧状态，运行 `check` 检查结构、metadata、链接、来源路径、支持的 symbol 和文件指纹。
2. 读取 map、module 和 flow，结合入口、路由、Consumer、Job、SQL、构建与配置搜索核对导航。记录已搜索范围、未检查范围和未归属入口；脚本只检查已记录关系。
3. 找出 changed、broken、known-gap 页面，以及涉及权限、事务、状态交接、异步、外部副作用、幂等、补偿和恢复的关键内容。
4. 根据风险重新阅读相关代码，核对 claim、行为和背景材料的适用范围，按需补充或局部更新。记录实际复核页面。
5. 报告范围与版本、机械错误、来源变化、覆盖缺口、已复核与待复核页面、验证结果及限制、后续处理项。

## 记录边界

分别记录引用有效、源码未变、AI 已复核、测试已执行、行为已验证和运行时已确认。静态检查结果不能替代全部页面的语义复核，也不产生统一可信度分数。

先检查旧状态，再按[契约](../schema.md)保存复核和验证结果。未经复核的页面保留原基线；未执行的验证标记为 not-run。

Python 不可用时手工完成必要检查；Git 不可用时比较已有指纹。报告降级范围及无法确认的内容。
